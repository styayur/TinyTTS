# Native security and GUI compatibility — November 2026

The application retains the sherpa-onnx 1.13.8 native ABI and its original 13 Windows static libraries. A direct native 2.x migration was tested with the real reviewed Kokoro model and found to skip input words, including unknown English names, because the former eSpeak fallback is ignored. Non-silent PCM alone did not establish compatibility; the native acceptance wrapper now rejects skipped-input warnings. Do not accept that speech regression merely to update a build dependency.

The explicitly local `sherpa-onnx-sys` fork uses version `1.13.8+tinytts.zip9.1`. It backports exactly ZIP 9.1.3 as a build dependency and keeps upstream native 1.13.8 names/URLs. Original FFI source and Apache license bytes are unchanged and checked against the verified crates.io archive provenance. Windows uses the same SHA-pinned TAR archive; the upstream ZIP API is in the iOS build branch, not the Windows speech runtime. No iOS device validation is claimed. See `third-party/sherpa-onnx-sys/BACKPORT.json` and its README.

The GUI uses eframe 0.37 with its new `App::ui` root-UI integration. OpenGL/Glow is selected explicitly to retain the existing renderer; eframe's changed default WGPU backend is a separate migration. Native system-font fallback renders Chinese text without redistributing Windows fonts. Voice IDs 0–52 retain their names/order; the reviewed model's Spanish `em_santa` is appended at 53.

The compatible rustls-webpki, webpki-roots and Tokio patches are locked, and the current GUI accessibility chain replaces the old vulnerable quick-xml dependency. `cargo audit` reports zero known vulnerabilities with no ignored advisories. Informational unmaintained-package warnings remain visible (font/parser and non-Windows accessibility dependencies); this is not a claim that all dependencies have active maintenance. CI and the existing future release validation now run the same audit before packaging. No formal release is triggered by this change.

Validation uses only self-authored text and isolated synthetic files. It covers native inference with English, Chinese, Spanish, unknown names, speed, pre/in-flight cancellation, recovery and independent WAV parsing. Native GUI checks cover Chinese glyphs, playback/pause/resume/stop, appended voice selection, speed/settings persistence, native WAV export, maximize/restore, a missing-model error and recovery after valid configuration. Normal model data remains a separate explicit download with its exact reviewed hash; weights/audio are not published as CI artifacts.

These checks do not independently establish linguistic intelligibility, acoustic speaker output, alternate physical-device switching or every DPI/Windows version. Rodio's separate major migration must retain its own audio/device acceptance. Keep the exact-head formatting, strict Clippy, core/full native tests, optimized build, source/model trust checks and real inference gates.
